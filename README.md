# Paceline

A modern running and lifestyle website built with HTML, CSS and JavaScript.

## About

Paceline is a frontend web project focused on running, movement and an active lifestyle.

The website uses a clean editorial-inspired design with bold typography, large imagery and a simple colour palette. It includes a responsive homepage and a dedicated About page, along with small JavaScript interactions.

This project was built to practice frontend development, responsive design and Git/GitHub workflow.

## Features

- Responsive homepage
- Hero section with seasonal collection
- Shop by Category section
- New Arrivals product section
- Paceline brand story
- Men's, Women's and Kids' running collections
- Customer testimonials
- Newsletter subscription interaction
- Search button interaction
- Cart interaction
- Login and Sign Up interactions
- Interactive Shop links
- Dedicated About page
- Brand mission and values
- The Paceline journey section
- Visit Us section with location map
- Founders section
- Responsive layouts using fluid CSS

## JavaScript

JavaScript is used for simple interactive elements such as:

- Search
- Cart
- Login
- Sign Up
- Newsletter subscription
